open-rig

A viewer for open-tick traces. Everything runs in your browser; no file leaves your computer.

Examples:

Plots

Wheel to zoom, drag to pan, double-click to reset. With the plots focused, use the arrow keys and + or −.

A against B

B is read at A's times, with linear interpolation, where B has a value. Only columns that both traces have are compared.

What this reads

The CSV that open-tick writes: a header of column names, then one row per step, with no quotes. An empty cell is a gap. See the trace format. Without a layout, number columns are grouped by the unit their name ends in (_rpm, _nm, _pct, _bar, _kpa, _c), and text columns and 0/1 columns are drawn as state strips.
